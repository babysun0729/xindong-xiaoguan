心动小馆 · 永久部署指南

按以下步骤操作，部署后获得24小时在线的固定网址

方法一：Render 部署（推荐）
1

注册 GitHub 账号

打开 github.com/signup，用邮箱注册一个免费账号（如果已有账号跳过此步）。

2

创建新仓库

  1. 登录后点右上角 + → New repository
  2. 仓库名填：xindong-xiaoguan
  3. 选择 Public（公开）
  4. 勾选 Add a README file
  5. 点 Create repository
3

上传项目文件

  1. 在仓库页面点 Add file → Upload files
  2. 把以下 5 个文件拖进去：index.html styles.css app.js server.py requirements.txt
  3. 文件都在你的 新建文件夹 (2) 里面
  4. 点 Commit changes 提交
注意：不要上传 xindong.db 文件，那是本地数据库
4

注册 Render 账号

打开 render.com/register，点 Sign up with GitHub 用刚才的GitHub账号注册。

5

创建数据库

  1. 进入 Render 控制台，点 New + → PostgreSQL
  2. Name 填：xindong-db
  3. 其他默认，点 Create database
  4. 创建完成后，找到 Connections 里的 Internal Database URL，复制它
这个 URL 就是 DATABASE_URL，待会要用
6

创建 Web 服务

  1. 回到控制台，点 New + → Web Service
  2. 选择刚才创建的 xindong-xiaoguan 仓库
  3. 填写配置：
    • Name：xindong-xiaoguan
    • Runtime：Python 3
    • Build Command：pip install -r requirements.txt
    • Start Command：gunicorn server:app
  4. 展开 Environment，添加环境变量：
    • Key 填 DATABASE_URL，Value 粘贴刚才复制的数据库URL
  5. 点 Create Web Service 开始部署
7

等待部署完成

Render会自动安装依赖并启动服务，大约2-3分钟。看到状态变为 Live 就成功了！

你的永久网址是：https://xindong-xiaoguan.onrender.com

免费版闲置15分钟后会休眠，首次访问需要等30秒唤醒。之后就可以一直用了。
方法二：PythonAnywhere（备选）
1

注册账号并上传文件

  1. 打开 pythonanywhere.com 注册免费账号
  2. 进入 Files 页面，上传 5 个文件（同上）
  3. 进入 Web 页面，点 Add a new web app
  4. 选择 Flask 框架，Python 版本选 3.10
  5. 路径填 server.py
2

安装依赖

进入 Consoles 页面，打开 Bash 控制台，运行：

pip install flask werkzeug gunicorn

你的网址是：你的用户名.pythonanywhere.com

PythonAnywhere 免费版不需要外部数据库，直接用SQLite，但限制较多

部署完成后

把你的永久网址发给朋友，他们随时打开就能注册使用
不需要你开电脑，24小时在线
